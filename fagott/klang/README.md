# Fagott-Klang

„Bassoon“ (Programm 70) aus **GeneralUser GS v2.0** von S. Christian Collins – https://schristiancollins.com/generaluser.php
Lizenz: `LIZENZ-GeneralUser-GS.txt`.

16 Töne von B₁ (MIDI 34) bis g″ (MIDI 79) im Abstand einer kleinen Terz, je 4,2 s gehalten plus Ausklang,
gerendert mit spessasynth_core ohne Effekte, gemeinsam auf −3 dBFS normalisiert, Mono-MP3 (112 kbit/s).
Dateiname = MIDI-Tonnummer. Die App spielt den gleichmäßigen Mittelteil in Schleife, solange gehalten wird.
